# Customer System B

City 311 is a municipal service-request system. The city has residents, staff
members, departments, districts, historical records, public request numbers,
and customer-owned mapping, mail, identity, storage, and work-order systems.

The supplied system is a runnable Corteza scaffold plus the frozen City 311 API
and data contract. It includes no implementation of the City 311 request
workflow. The contract is intentionally supplied so the delivery can integrate
with the existing customer vocabulary and interfaces without inventing a new
product model.

Synthetic fixture identities and records represent residents, Streets staff,
Parks staff, districts, and historical request identifiers. They contain no
real personal information.
